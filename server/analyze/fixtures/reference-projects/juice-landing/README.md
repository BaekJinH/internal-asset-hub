# juice-landing (reference project fixture)

A deliberately-messy sample reference project for the (B)② loader self-check. Not a component — the loader's
extension filter must ignore this file. The `globals.css` exercises dark-mode/@media/@layer/comment/omitted-token/
unterminated-declaration edge cases; `components/` holds valid components (some nested), one broken (rejected by
conformance), and one empty (skipped).
